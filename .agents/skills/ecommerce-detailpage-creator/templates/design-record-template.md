# 设计记录模板

按请求选择适用区块；空字段写待核实／不适用并说明原因，不能编造值。保留方案与操作版本；模板字段名不进入成品图。

## 事实和来源

```text
商品／型号：
本次范围：事实 / 策划 / 提示词 / 生成
来源 S01：本商品实图路径；用途=产品身份
来源 S02：参数图或用户确认记录；用途=参数依据
来源 S03：可选参考图；用途=风格 / 结构，不提供产品事实

事实 F01：内容；状态=图像可见 / 文档或用户提供 / 待核实 / 冲突
来源与位置：S01 的主体正面；或 S02 的容量行
能支持：
不能支持：
待补／冲突处理：
```

缺资料时集中列出影响结果的具体问题。不要用「图片上似乎有 6」确认 6L，也不要用用户授权生图消除事实冲突。

## 顾虑映射

| 顾虑编号 | 关联事实 | 买家问题 | 画面证据 | 有依据的回答 | 待补内容 |
|---|---|---|---|---|---|
| Q01 | F01 | 能否观察内部状态？ | 正面真实窗口和可观察区域 | 通过窗口观察食物外观 | 是否有照明／能否运行中观察，按实际证据确认 |

## 分屏方案卡

先给整套证据覆盖结论：请求屏数、有依据的屏、待补屏、建议保留或调整的屏数及原因。待补资料的结构草案与可直接生成的完整方案分别标记，不能把重复改标题当成新增证据。

```text
方案版本：V1
屏号／阅读顺序：P02 / 2
作用：核心功能证据
主顾虑：Q01
事实：F01，其他未经确认项不入图
标题：
辅助文案：
标签：
画面证据：
布局：主体／证据特写／标题区／标签区
共同视觉约束：
尺寸及交付形式：独立图 / 长图切片
禁止推断：
验收点：
确认状态及范围：待确认 / 用户已确认 V1 的具体内容
```

## 逐屏提示词模板

```text
任务：生成一屏完整电商详情页，包含以下准确中文文字。
商品参考：实际传入的本商品图片及参考编号。
保持：本商品颜色、比例、窗口位置、面板和配件结构。
风格参考：仅用于已列明的风格／结构因素。
主顾虑：本屏只回答的一个问题。
依据：已核实事实编号与允许表达的范围。
画面证据：具体呈现什么、放在哪里、如何支持回答。
标题：逐字文案。
辅助文案／标签：逐字文案；没有则不添加。
布局：标题区、主体区、证据区、留白及安全区。
整套约束：配色、字级、光线、图标风格、商品身份。
画幅／尺寸：已确认的要求；工具不支持精确尺寸时说明实际输出。
禁止：添加未确认参数、认证、健康功效、销量、促销和新功能；
不得将场景示意写成实拍、实测或用户口碑，不添加模板字段名。
验收：中文、参数、产品一致性、证据可见、无空白与裁切。
```

## 记录生成与交付

```text
批次：商品标识 / V1
P01：未提交 / 已提交 / 结果不明 / 生成成功待保存 / 已保存 / 自检失败 / 待用户验收 / 已认可
工具与模型：实际选择，不猜工具 ID
授权范围：确认版本、允许提交范围及收费授权依据
任务标识：实际返回值；未返回则记录未取得
文件：实际绝对路径或服务返回的可访问链接
实际尺寸：
自检：通过项、失败项、未检查项
返修：问题、返回阶段、受影响屏、版本
归档：本地位置或已获授权且实际写入的外部素材库位置
```

本地可采用 `商品标识/V1/P01-购买理由.png` 等命名，并配一份交付清单；以用户现有素材规范优先。遇到同名文件新增版本或唯一名称，不覆盖已有结果。
