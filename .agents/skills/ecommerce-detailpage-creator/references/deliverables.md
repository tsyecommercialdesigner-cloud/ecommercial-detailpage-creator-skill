# 交付模板与示例

适用于策划、提示词或整套成品交付。以下为可调整的 Markdown 记录约定，不是宿主 API 或固定 JSON Schema。路径由用户工作区及授权决定，不能向技能安装目录写业务结果。

## 事实和来源

```text
商品／型号：
本次范围：事实 / 策划 / 提示词 / 生成
来源 S01：本商品实图路径；用途=产品身份
来源 S02：参数图或用户确认记录；用途=参数依据
来源 S03：可选参考图；用途=风格 / 结构，不提供产品事实

事实 F01：内容；状态=图像可见 / 文档或用户提供 / 待核实 / 冲突
来源与位置：S01 的主体正面；或 S02 的容量行
能支持：
不能支持：
待补／冲突处理：
```

缺资料时集中列出影响结果的具体问题。不要用「图片上似乎有 6」确认 6L，也不要用用户授权生图消除事实冲突。

## 顾虑映射

| 顾虑编号 | 关联事实 | 买家问题 | 画面证据 | 有依据的回答 | 待补内容 |
|---|---|---|---|---|---|
| Q01 | F01 | 能否观察内部状态？ | 正面真实窗口和可观察区域 | 通过窗口观察食物外观 | 是否有照明／能否运行中观察，按实际证据确认 |

## 分屏方案卡

先给整套证据覆盖结论：请求屏数、有依据的屏、待补屏、建议保留或调整的屏数及原因。待补资料的结构草案与可直接生成的完整方案分别标记，不能把重复改标题当成新增证据。

```text
方案版本：V1
屏号／阅读顺序：P02 / 2
作用：核心功能证据
主顾虑：Q01
事实：F01，其他未经确认项不入图
标题：
辅助文案：
标签：
画面证据：
布局：主体／证据特写／标题区／标签区
共同视觉约束：
尺寸及交付形式：独立图 / 长图切片
禁止推断：
验收点：
确认状态及范围：待确认 / 用户已确认 V1 的具体内容
```

## 逐屏提示词模板

```text
任务：生成一屏完整电商详情页，包含以下准确中文文字。
商品参考：实际传入的本商品图片及参考编号。
保持：本商品颜色、比例、窗口位置、面板和配件结构。
风格参考：仅用于已列明的风格／结构因素。
主顾虑：本屏只回答的一个问题。
依据：已核实事实编号与允许表达的范围。
画面证据：具体呈现什么、放在哪里、如何支持回答。
标题：逐字文案。
辅助文案／标签：逐字文案；没有则不添加。
布局：标题区、主体区、证据区、留白及安全区。
整套约束：配色、字级、光线、图标风格、商品身份。
画幅／尺寸：已确认的要求；工具不支持精确尺寸时说明实际输出。
禁止：添加未确认参数、认证、健康功效、销量、促销和新功能；
不得将场景示意写成实拍、实测或用户口碑，不添加模板字段名。
验收：中文、参数、产品一致性、证据可见、无空白与裁切。
```

## 记录生成与交付

```text
批次：商品标识 / V1
P01：未提交 / 已提交 / 结果不明 / 生成成功待保存 / 已保存 / 自检失败 / 待用户验收 / 已认可
工具与模型：实际选择，不猜工具 ID
授权范围：确认版本、允许提交范围及收费授权依据
任务标识：实际返回值；未返回则记录未取得
文件：实际绝对路径或服务返回的可访问链接
实际尺寸：
自检：通过项、失败项、未检查项
返修：问题、返回阶段、受影响屏、版本
归档：本地位置或已获授权且实际写入的外部素材库位置
```

本地可采用 `商品标识/V1/P01-购买理由.png` 等命名，并配一份交付清单；以用户现有素材规范优先。遇到同名文件新增版本或唯一名称，不覆盖已有结果。

## 空气炸锅的有界示例

这是合成演示，只有两项输入事实：本商品正面照片可见黑色机身、银色把手及前窗；用户确认烹饪时可通过该窗观察食物。未提供容量、功率、菜单和清洗说明。

事实 F01「前窗」对应 Q01「能否看到食物外观」。可交付一屏计划：

> 标题：食物状态，透窗看得见。画面：保持本商品前窗形状和位置，透窗可见食物；用标为“烹饪示意”的外观变化辅助说明。标签：可视窗口。禁止添加容量、温控、预约、健康承诺和减少失败率的量化结论。

这只能形成有依据的一屏计划及其提示词；要形成六屏，需要补充其他真实信息或提出待核实结构草案。不能照抄教程的 6L、8 种预设或整机可冲洗。

## 正常、反例与恢复

- 输入实图及本型号确认参数，用户要求先做六屏方案：交付事实表、顾虑表、P01–P06 卡片及待确认项；生成次数为零。
- 用户只要一张 SKU 白底图：转到单图能力，保留该任务输入，不额外展开多屏策划。
- 用户确认方案但工具不可用：交付方案和逐屏提示词，状态为提示词已交付，明确尚无成品。
- P01/P02 已保存，P03 超时且有任务号，P04–P06 未提交：先查 P03；不重提 P01–P03。按授权可继续 P04–P06，并交付逐屏状态，不能称全部完成。
- P02 乱码，其余图通过：定位文字问题、保留原文件，按授权局部修复并重新核对该屏与整套一致性；不重新生成整套。
